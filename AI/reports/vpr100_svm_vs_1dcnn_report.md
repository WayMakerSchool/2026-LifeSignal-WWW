# V-PR100 SVM·1D-CNN 비교 리포트

## 결론

현재 V-PR100 데이터에서는 **SVM을 최종 모델로 선택하는 편이 더 타당합니다.** 두 모델 모두 높은 성능을 보였지만, SVM이 평균 정확도와 Macro F1, 구조 대상인 사람의 재현율, 세션 변화에 대한 안정성에서 1D-CNN보다 우세했습니다. 학습과 추론도 더 빠르고 모델 파일도 작았습니다.

다만 차이는 절대적으로 크지 않습니다. 1D-CNN은 개 분류에서 더 좋은 결과를 냈으며, 데이터 세션이 더 많이 쌓이면 결과가 달라질 수 있습니다.

## 데이터와 평가 방법

- 원본 데이터: `AI/data/vpr100_samples.csv`
- 원본 측정값: 2,394행
- 독립 수집 세션: 8개
  - `empty`: 1,200행, 4세션
  - `dog`: 600행, 2세션
  - `human`: 594행, 2세션
- 입력 채널: `presence_score`, `distance_mm`, `status`
- 한 입력 윈도우: 연속 측정값 25개
- 윈도우 이동 간격: 5개
- 전체 윈도우: 446개
- 데이터 증강: 사용하지 않음

같은 세션의 데이터가 학습과 평가에 섞이면 실제보다 성능이 높게 측정될 수 있으므로, 행 단위 무작위 분할 대신 **세션 단위 분리 평가**를 사용했습니다. 사람 2세션 × 개 2세션 × 빈 공간 4세션에서 각각 한 세션씩 평가용으로 제외하는 **총 16개 조합**을 모두 실험했습니다.

1D-CNN의 학습 중단 시점은 외부 평가 세션이 아니라 학습 데이터 내부 검증 집합으로 결정했습니다. 따라서 외부 평가 세션을 학습 과정에서 미리 보지 않았습니다.

## 모델 구성

### SVM

- 25개 시계열에서 평균, 표준편차, 최솟값, 최댓값, 변화량 등의 통계 특징 추출
- 표준화 후 RBF 커널 SVM 사용
- 클래스 불균형 보정 적용
- 확률형 신뢰도 출력을 위한 보정 분류기 사용

### 1D-CNN

- `Conv1D(32, kernel=5)`
- Batch Normalization, ReLU, Max Pooling
- `Conv1D(64, kernel=3)`
- Batch Normalization, ReLU, Global Average Pooling
- Dense 32, Dropout 0.3, Softmax
- 학습 파라미터: 9,187개

## 핵심 결과

| 평가 항목 | SVM | 1D-CNN | 해석 |
|---|---:|---:|---|
| 평균 정확도 | **99.10%** | 98.84% | SVM +0.26%p |
| 평균 Macro F1 | **99.10%** | 98.83% | SVM +0.27%p |
| 정확도 표준편차 | **0.90%p** | 1.60%p | SVM의 세션별 변동이 약 44% 작음 |
| 최저 정확도 | **97.60%** | 95.21% | SVM +2.40%p |
| 사람 재현율 | **98.18%** | 96.48% | SVM +1.70%p |
| 평균 학습 시간 | **0.011초** | 4.905초 | CNN이 약 432배 오래 걸림 |
| 단일 윈도우 추론 시간 | **0.953ms** | 2.269ms | CNN이 약 2.4배 느림 |
| 저장 모델 크기 | **46,099B (약 45KB)** | 164,987B (약 161KB) | CNN이 약 3.6배 큼 |

학습 및 추론 시간은 현재 Mac CPU에서 동일 조건으로 측정한 상대 비교값입니다. 라즈베리파이에서의 절대 실행 시간으로 해석하면 안 되지만, 어느 모델이 더 가벼운지를 비교하는 근거로는 사용할 수 있습니다.

## 누적 혼동행렬

16개 평가 조합의 결과를 합산했습니다. 같은 세션이 서로 다른 학습 조합에서 여러 번 평가되므로 아래 건수는 고유 원본 개수가 아니라 **모델 안정성을 비교하기 위한 누적 예측 건수**입니다.

라벨 순서: `사람`, `빈 공간`, `개`

### SVM

| 실제 \ 예측 | 사람 | 빈 공간 | 개 |
|---|---:|---:|---:|
| 사람 | 864 | 0 | 16 |
| 빈 공간 | 0 | 896 | 0 |
| 개 | 4 | 4 | 888 |

### 1D-CNN

| 실제 \ 예측 | 사람 | 빈 공간 | 개 |
|---|---:|---:|---:|
| 사람 | 849 | 30 | 1 |
| 빈 공간 | 0 | 896 | 0 |

1D-CNN은 개와 빈 공간 분류가 매우 강했지만 사람 30건을 빈 공간으로 판단했습니다. SVM은 사람을 빈 공간으로 판단한 경우는 없었으나 사람 16건을 개로 판단했습니다. LifeSignal의 목적상 두 오류 모두 중요하지만, 구조 대상 자체를 없는 것으로 판단하는 오류를 줄이는 측면에서는 SVM 결과가 더 유리합니다.

## 기본 분할로 저장한 최종 1D-CNN

프로젝트의 기본 세션 분할로 최종 1D-CNN 모델도 저장했습니다.

- 검증 윈도우: 167개
- 정확도: 98.20%
- Macro F1: 98.20%
- 사람: 55개 중 52개 정답, 3개를 빈 공간으로 오분류
- 개: 56개 모두 정답
- 빈 공간: 56개 모두 정답
- 모델: `AI/artifacts/vpr100-cnn.keras`
- 메타데이터: `AI/artifacts/vpr100-cnn.json`

## SVM을 선택한 수치적 이유

1. **전체 분류 성능:** 평균 정확도와 Macro F1이 각각 0.26%p, 0.27%p 높았습니다.
2. **사람 감지 안전성:** 사람 재현율이 1.70%p 높았고, 1D-CNN에서 나타난 사람→빈 공간 오분류가 누적 비교에서는 발생하지 않았습니다.
3. **세션 변화 대응:** 정확도 표준편차가 0.90%p로 CNN의 1.60%p보다 작았으며, 최저 정확도도 2.40%p 높았습니다.
4. **소규모 데이터 적합성:** 독립 세션이 8개뿐인 현재 조건에서 학습 파라미터 9,187개의 CNN보다 통계 특징 기반 SVM이 안정적이었습니다.
5. **경량 배포:** 학습은 약 432배, 단일 추론은 약 2.4배 빨랐고 모델 크기는 약 28% 수준이어서 라즈베리파이 배포 부담이 작습니다.

## 발표용 요약 문장

> 동일한 V-PR100 원본 측정값 2,394개를 25개 단위 시계열로 구성하고, 수집 세션이 학습과 평가에 겹치지 않도록 16개 조합을 비교했습니다. SVM은 평균 정확도 99.10%, 사람 재현율 98.18%로 1D-CNN의 98.84%, 96.48%보다 높았고, 최저 정확도도 97.60%로 CNN의 95.21%보다 안정적이었습니다. 또한 학습은 약 432배, 단일 추론은 약 2.4배 빨라 현재의 소규모 데이터와 라즈베리파이 기반 실시간 시연 환경에 더 적합하다고 판단했습니다.

## 해석 시 주의사항

- 현재 데이터는 실제 사람과 반려동물 전체가 아니라 공모전 프로토타입 환경에서 수집한 인형 기반 데이터입니다.
- 독립 세션이 8개로 적으므로 99%대 결과를 일반적인 실제 환경 정확도로 확대 해석하면 안 됩니다.
- 윈도우가 5개 간격으로 겹치므로 같은 평가 세션 내부의 윈도우끼리는 상관관계가 있습니다. 이를 보완하기 위해 학습·평가 세션 자체는 완전히 분리했습니다.
- 데이터가 크게 늘고 다양한 대상·거리·환경이 포함되면 1D-CNN이 SVM을 앞설 가능성이 있습니다. 따라서 현재 결론은 **현재 확보된 V-PR100 프로토타입 데이터 기준**입니다.
